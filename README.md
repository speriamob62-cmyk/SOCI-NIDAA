# N.I.D.A.A. – Gestionale Soci

Gestionale per l'associazione: anagrafica soci, scheda PDF, tessera, ricevute, prima nota e rendiconto per cassa.

Applicazione web installabile (PWA). I dati restano nel browser del dispositivo, non nel repository.

## Pubblicazione con GitHub Pages
1. Carica tutti i file di questa cartella nella radice del repository.
2. Settings → Pages → Branch `main` / cartella `/ (root)` → Save.
3. Apri `https://TUO-UTENTE.github.io/NOME-REPOSITORY/` da Chrome.
4. Menu ⋮ → Installa app (o Aggiungi a schermata Home).

Non caricare mai su GitHub dati dei soci.
